# Norsecraft roadmap

## Done
- Core RTS: two mirrored factions (Vikings, Jötnar), economy, buildings, upgrades, fog of war, minimap
- Computer opponent: Beginner, Easy, Normal, Hard
- Building repair
- Spellcasters: heal, summon, storm
- Save, load and autosave
- Generated music and unit voices
- Phones and tablets: touch controls, zoom, add to home screen, offline
- Tutorial mission: ten guided steps ending in a raid

## Next, in order
1. **Campaign**: 5–6 story missions with goals (defend the village, raid the giants' mine, survive the waves, reach the World Tree) and story text between them.
2. **Heroes**: one levelling hero per side (a jarl / a champion of Ymir).
3. **Skirmish options**: map size (small / medium / large) and 1–3 enemy AIs.
4. **Ships and fjord maps**: shipyard, longships, carrying troops across water.
5. **Polish**: Patrol command, second upgrade level, army-size graph on the victory screen.

## Later
- **Online multiplayer** with friends: a small relay server so two browsers run the same game in sync. Needs a free host for the server.
